# Gusli Guest QR Page V2

Новый лёгкий прототип гостевой страницы. Старое приложение не используется.

## Как открыть

Открой `index.html` в браузере или запусти локальный сервер из этой папки:

```bash
python -m http.server 4173
```

После этого страница будет доступна на `http://localhost:4173`.

## Что проверяем в дизайне

- Гость сразу понимает, где он находится и сколько стоит заявка.
- Поиск и выбор трека занимают центр интерфейса.
- Оплата всегда доступна в нижней панели после выбора трека.
- Очередь видна после успешной mock-оплаты, но не перегружает первый экран.
